# 🚗 C-Engine-Project-010 — Driver Safety Rating System 🛑⚙️

Part of my **C-Engine Series**, where I merge real mechanical engineering with C programming to build logic-driven tools.

## 🔥 About
This program evaluates driver safety based on **vehicle speed** and **seatbelt status**, similar to decision logic used in modern ECU safety systems.

## 📐 Logic Used
- If speed >= 120 → `DANGER MODE`
- Else if seatbelt == 0 → `UNSAFE MODE`
- Else → `SAFE DRIVER`

## 🧠 Concepts Used
- `scanf()` for input
- Variables (`int`)
- `if–else if–else` decision-making
- Real-life automotive application

## 🧩 Example
**Input:**  
Speed: `100`  
Seatbelt: `0`

**Output:**  
`UNSAFE MODE`
